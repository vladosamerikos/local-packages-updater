# Icono de Actualizaciones · 0.3

El maestro app-icon-master.png fue generado el 29 de septiembre de 2026 con
la herramienta integrada image_gen, en modo generación con fondo transparente.
Se conserva el resultado original. scripts/generate-icons.py usa Pillow
únicamente para exportarlo con Lanczos a 16, 24, 32, 48, 64, 128, 256, 512 y
1024 px. Los dos iconos simbólicos de bandeja se dibujan desde código.

## Prompt final

Use case: logo-brand. Asset type: Linux desktop application launcher icon, one square 1024x1024 master image. Primary request: a beautiful, highly polished icon for an app called Actualizaciones that checks and installs desktop app updates. Subject: a single bold pair of pearl-white curved refresh arrows forming a clear circular loop, centered on a rich royal-blue rounded square tile. Style: refined GNOME desktop icon with subtle sculpted depth, a satin blue surface, delicate bevels, cool cyan highlights at the upper edge and gentle darker cobalt shading at the bottom. Front-facing orthographic view, crisp clean silhouette, generous mark size, readable at 32 pixels. Tile occupies about 88 percent of the square canvas, transparent outside its rounded silhouette. Elegant, calm, premium finish. No text, no letters, no app screenshots, no multiple variants, no icon grid, no surrounding scenery, no giant drop shadow, no excessive glow. Produce exactly one finished icon with genuine alpha transparency outside the tile.

Desde la raíz del proyecto:
